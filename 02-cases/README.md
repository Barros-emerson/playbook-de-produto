# Cases

Projetos reais, anonimizados. Todos seguem a mesma lógica, adaptada ao que cada projeto documenta: **contexto, problema, discovery, insights, decisão, requisitos, solução, MVP, riscos, validação, resultado e aprendizado**.

Cada case responde: qual era o problema, como descobri, o que foi decidido, por quê, como virou requisito, como o time sabia que estava correto e qual foi o resultado documentado.

|---|---|---|---|

| 02 | [Assistente jurídico com RAG](02-assistente-juridico-rag/) | Jurídico | RAG, agentes especializados, auditoria de escopo real, modelo de custo de IA |
| 03 | [Gestão de escopo no setor imobiliário](03-gestao-de-escopo-imobiliario/) | Imobiliário | Decisão por valor, esforço, risco e previsibilidade; renegociação de escopo; custo de plataforma |
| 04 | [Agente de voz em call center](04-agente-de-voz-call-center/) | Serviços financeiros | Agente de voz, SIP Trunk, auditoria pós-entrega, gestão de crise, critérios binários |

## Convenções

- **[NÃO DOCUMENTADO]:** a informação existe ou existiu, mas não está comprovada neste portfólio.
- **[A VALIDAR]:** informação que depende de confirmação.
- **[ILUSTRATIVO]:** exemplo criado para mostrar um formato de escrita; não foi extraído do projeto original.
- **Arquitetura conceitual:** representação de produto, não arquitetura técnica oficial.
