# Playbook de Produto

Método, templates e casos de um Product Owner que trabalha com implementação de agentes de IA e produto digital sob medida.

Este repositório existe para mostrar **como** eu trabalho, não só **o que** entreguei. Todos os casos estão anonimizados: nomes de clientes, contatos, valores e identificadores internos foram removidos.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| [`metodo/`](metodo/) | Como conduzo discovery e priorização |
| [`templates/`](templates/) | Modelos de PRD, história de usuário e Definition of Done |
| [`cases/`](cases/) | Projetos reais, anonimizados, no formato contexto, problema, decisão e aprendizado |

## Princípios

1. **A dor do cliente vem antes da tecnologia.** IA é meio, não fim.
2. **Todo critério de aceite é testável.** Se depende de interpretação, está mal escrito.
3. **Investigação não é critério de aceite.** Causa-raiz e evidência de QA vão para tarefa ou DoD.
4. **Escopo é contrato.** O que não está no PRD aceito não está no projeto.
5. **Entrega só termina no aceite.** Auditoria pós-entrega é parte do trabalho, não opcional.
