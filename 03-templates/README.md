# Templates

Modelos reutilizáveis, na ordem em que entram no fluxo de trabalho. Refletem o método aplicado nos cases; não são um framework teórico. Livres para uso e adaptação, com atribuição.

| Template | Quando usar |
|---|---|
| [discovery.md](discovery.md) | Preparar, conduzir e registrar uma reunião de discovery |
| [prd.md](prd.md) | Consolidar o escopo do projeto em uma fonte única da verdade |
| [priorizacao.md](priorizacao.md) | Filtrar e pontuar oportunidades, ou decidir o que manter no escopo |
| [user-story.md](user-story.md) | Escrever cada história do backlog |
| [criterios-de-aceite.md](criterios-de-aceite.md) | Escrever e revisar critérios de aceite testáveis |
| [checklist-mvp.md](checklist-mvp.md) | Definir e revisar o recorte de MVP |
| [riscos.md](riscos.md) | Registrar e acompanhar riscos, premissas e dependências |
| [dor-dod.md](dor-dod.md) | Checar se a história pode entrar no desenvolvimento e se está pronta |
| [handoff-produto-dev.md](handoff-produto-dev.md) | Liberar a demanda do Produto para o Desenvolvimento |
